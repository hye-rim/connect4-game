# 커넥트4 🔴

세로로 세워진 판에 돌을 떨어뜨려 **가로·세로·대각선으로 4개를 먼저 이으면** 이기는 보드 게임. 컴퓨터와 하거나 온라인으로 친구와 겨룰 수 있어요. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 판은 가로 7칸 × 세로 6칸. 열을 고르면 돌이 그 열의 맨 아래 빈칸까지 떨어진다. 빨강이 먼저 둔다
- 4개를 먼저 이으면 승리(5개 이상도 승리), 판이 꽉 차면 무승부. 이긴 4개는 반짝이고 나머지 돌은 흐려진다
- **컴퓨터 대전**: 쉬움(가끔 실수) · 보통(5수 앞) · 어려움(시간 안에 깊이 읽는 알파-베타), 내 돌 고르기, 무르기
- **온라인**: 빠른 대전, 방 코드 만들기·들어가기, 초대 링크, 기권, 한 판 더(빨강·노랑 교대), 한 수 30초(넘기면 시간패), 끊겨도 30초 안에 돌아오면 이어서
- 최고 기록은 컴퓨터 상대 승수 `connect4Wins`(로비 카드에 표시), 전적은 `connect4Record` · `connect4Online`
- 조작: 열을 클릭/탭 · PC는 ←→ + Space, 숫자 1~7, Z 무르기, M 소리, Esc 메뉴

## 실행
```bash
npm install
npm start        # http://localhost:3008  (PORT 환경변수로 바꿀 수 있다)
npm test         # 규칙·컴퓨터·서버 시험
```

판 규칙과 컴퓨터는 `public/rules.js`(브라우저와 서버가 같이 쓴다), 화면·입력·온라인은 `public/game.js`, 방·매칭은 `server.js`. 서버가 모든 수를 규칙대로 직접 확인한다(차례·열 번호·꽉 찬 열).
